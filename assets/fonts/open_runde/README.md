# Open Runde

Unmodified desktop OpenType fonts from Laurids Kern's Open Runde project:
https://github.com/lauridskern/open-runde

Pinned upstream revision: `3e7ed7f3cdfa5523766db7e430066472615fc935`.
Source directory: `src/desktop/`.

Bundled weights: Regular 400, Medium 500, Semibold 600, Bold 700.
Licensed under the SIL Open Font License 1.1; see `OFL.txt`.

Scholaris uses the bundled `OpenRunde` family on every platform, without runtime
font downloads or reliance on Apple's SF Pro Rounded. The user approved this
replacement for Geist on November 1, 2026. Retained Geist files are legacy assets,
not the selected app font.
