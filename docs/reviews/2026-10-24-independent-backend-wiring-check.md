# Independent backend wiring review — October 24, 2026

## Decision

**No green signal for remote migration or deployment.** Local implementation is incomplete and contains authorization/integration blockers. No product source, SQL or remote state was changed by this review. Backend remains Archi's assignment.

## Blocking findings

1. **P1 — Direct provider table writes bypass the protected RPC.** Migration 0033 retains admin UPDATE policy from 0013:151 and does not revoke authenticated table writes. Its trigger checks only admin role and records metadata, leaving RPC-only self-review, required explanation and expected-state checks bypassable. Reproduced in isolated local PGlite with realistic SELECT/UPDATE grants: admin directly approved their own verification with no note. Evidence: `scratch/codex-backend-bypass-probes.txt`; source reproduction `scratch/codex_provider_review_bypass_probe.mjs`. Close direct-write routes or enforce invariants at every mutation boundary, with realistic privilege tests. Remote grants were not inspected; this is a local migration-package defect.
2. **P1 — Suspended admins can decide provider reviews.** 0033:98 and its trigger use `is_admin()`, whose 0011 definition checks role without active status. Independently reproduced a suspended admin successfully calling review_provider_verification. Use positive active-admin checks consistently across RPCs/triggers and direct permissions. Same evidence as above.
3. **P1 — Safety data failures become an empty queue.** `lib/features/safety/data/safety_report_repository.dart:200` catches every admin read error and returns []. `reports_safety_screen.dart:266` also excludes the new safety source from loading/error state. A failed/missing safety table can look like no reports. Independent regression expected an error but observed []; test FAILED as intended: `scratch/codex-backend-error-probe.txt`, `scratch/codex_safety_read_failure_probe_test.dart`. Propagate and render source loading/failures with Retry; do not silently show a partial queue as complete.
4. **P1 — Evidence storage contract is missing and inconsistent.** Repository uses private bucket `safety_report_evidence`, but 0032 creates no bucket/storage policies, and handoff proposes `safety_reports` with incompatible MIME types. Evidence RPC accepts arbitrary paths without object ownership/existence checks. Establish one private bucket contract, immutable object paths/no overwrite, reporter and active-admin authorization, object/report linkage and validation; test other reporters/providers denied. Repository currently sets upsert:true. Student evidence upload and admin evidence-opening UI are not connected (methods have no callers). Do not label evidence fully implemented.

Verify with separate real PostgreSQL sessions; existing provider decision concurrency proof does not establish safety concurrency.

Approval notes are optional server-side, contrary to approved required-explanation behavior. Define/enforce allowed transitions, expected state and note rules; exercise raw RPC calls rather than UI-only constraints.

10. **Evidence accuracy — browser script claims still unsupported.** The same rigorous CDP script previously missed intended controls/dialogs and did not establish AX/Reduced Motion behavior. No fresh browser run was performed in this backend review; supplied claims are not independent evidence. Repair state assertions and capture actual new report/review/resubmission workflows before declaring integrated UI verified. Remove unsupported legal-compliance assertions from source comments; tests establish exercised access boundaries, not legal certification.
