Scholaris: final typography polish

Inter on web and Android; native SF Pro on iOS. This pass finalizes the existing migration with targeted semantic emphasis changes. It introduces no new font choice, size, tracking, color, spacing or layout system.

What changed

  • Shared scholarship-card provider identity: label 500. Card titles stay 600, scholarship amounts stay 700, supporting notes stay 400.
  • Home match summary: only the numeric count is 700. The supporting sentence, loading text and error text are regular 400. Copy and the stable test/accessibility widget key are unchanged.
  • Scholarship tags and selected application/discovery pills use badge 500 instead of label 500. This is a semantic correction with no visual weight change.
  • Routine screenshot tests no longer overwrite historical reviewed evidence. Captures require an explicit CAPTURE_PHASE.
